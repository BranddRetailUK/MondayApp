# Black B45 front reference

`b45-black-front-v1.png` is the blank generated B45 image used for Plastic Head
order 51346, retained by the Plastic Head workflow and incorporated into the
native Proof Generator on 19 October 2026. It contains no customer artwork.

The user confirmed the design-to-beanie scale in those proofs as accurate on
19 October. Preserve that accepted visual scale: artwork width / 200 mm is its
fraction of the cropped beanie width. The 200 mm value originated as an estimated
flat width; the acceptance is of the visual design scale, not a supplier measurement.

The image-specific turn-up rectangle is x=.10, y=.615, width=.80, height=.385 in
cropped garment coordinates. Artwork is centred in this region at its requested
physical proportions, never stretched or reduced to fit. Oversized artwork fails.

Only verified black B45 / BB45 / BC045 products use this reference. Other colours
and products require their own supplier evidence, view assessment and cached blank.
The image hash and version are pinned in proofHeadwear.js; changed pixels need a
reviewed region and new version. Do not overwrite this version to update a template.
