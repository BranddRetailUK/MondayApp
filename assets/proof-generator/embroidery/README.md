# Thread material v1

`thread-material-v1.png` is a neutral grey machine-embroidery material scan generated with GPT Image on 2026-10-14. It contains no customer artwork. The renderer reuses its bounded luminance variation as fine thread texture inside the existing DST preview.

The customer image's width, height, all alpha bytes, stitch directions and layout are retained. Only RGB shading changes. No customer logo is regenerated, retyped, dilated, cropped differently or sent to an image model. Original files remain production sources. This proof finish does not predict a physical sew-out or remove sewing connectors that are encoded as actual stitches.

Keep this versioned asset stable: changing it changes regenerated proofs. Saved proof PDFs continue to be downloaded verbatim.
